FACE WARS - how to run
1. Install Node.js (nodejs.org, LTS).
2. In this folder run:  node server.js
3. Open http://localhost:3000 in Chrome or Edge on the laptop.
4. Phones scan the QR on the result screen (must be on the same Wi-Fi as the laptop).
To change the game: npm install, edit src/App.jsx, then npm run build, then node server.js
